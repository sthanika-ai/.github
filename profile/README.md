## Work in the open

| Project | What it is |
|---|---|
| **[Indic-KCC-Agri-Advisory-Benchmark](https://github.com/sthanika-ai/Indic-KCC-Agri-Advisory-Benchmark)**<br/>[`datasets/sthanika-ai/Indic-KCC-Agri-Advisory-Benchmark`](https://huggingface.co/datasets/sthanika-ai/Indic-KCC-Agri-Advisory-Benchmark) | Open-ended agricultural-advisory question answering in **11 Indian languages**, built from real farmer questions and the answers given by human agents at India's Kisan Call Centre. 500 questions sampled once and translated into all 11 languages, so cross-language comparisons are apples-to-apples. 5,500 rows, every one shipped with its translation-quality score.<br/><sub>⚠️ Benchmark only — not agronomic advice.</sub> |
| **[milu-llm-evaluation](https://github.com/sthanika-ai/milu-llm-evaluation)** | A reproducible pipeline and a completed campaign: **18 models × all 11 MILU languages**, end to end. Reports accuracy *and* real measured cost per 1K questions — plus a disclosed scoring-protocol bug affecting four hybrid-"thinking" model families that, uncorrected, inverts two models' rank.<br/><sub>MILU is AI4Bharat and IBM's benchmark; we run it as adopters, not authors.</sub> |

Every reported figure traces back to a raw model output through the pipeline that
produced it, so results can be independently reproduced or audited rather than
taken on faith.
